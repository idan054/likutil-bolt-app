## 📦 Deployment

### 🏃 Run Locally
To run the project locally, use:
```sh
npm run dev
```

### 🌐 Deploy to Netlify
#### `my-tests.likutil.co.il`
```sh
npx vite build && netlify deploy --prod --dir=dist --site=73927777-9725-4090-99b5-441982851b2a
```

#### `my.likutil.co.il`
```sh
npx vite build && netlify deploy --prod --dir=dist --site=a2dcfff4-8c46-4d25-a395-246c27964806
```



## 🔗 GitHub & Bolt.AI Integration

### Get from GitHub to Bolt.AI
Just use this link:
[Open in Bolt.AI](https://bolt.new/~/github.com/idan054/likutil-bolt-app)

### Push to GitHub from Bolt.AI
1. Download the ZIP file from Bolt.AI.
2. Extract the contents.
3. Push the extracted files to GitHub manually.

Use the **Bolt to GitHub** Chrome Extension for a seamless push process.
