# likutil-bolt-app

The core of this project has been made using Bolt.AI which is pretty Amazing,

### Heres how u can integrate the Github Repo with Bolt to Continue use it:

## Pull Repo (Update Bolt.Ai)

⚠️ Before do changes with Bolt AI You must sync it with the Github repo
Bolt only knows its own files

#### Manually move folders from your machine to Stackblitz.com

Do it using the "Open In Stackblitz" Button.
